Гостиница Талер

База отряда в Нижнем улье. Принадлежит Халикарну через подставных лиц.

  • Не одно строение, а компактный жилой квартал, где тянут лямку ~20 тысяч душ.
  • Формально — общежитие для персонала кораблей, прибывших на Тихий Торг. Вокруг вырос торговый квартал: дешёвые наркотики, импланты, товары, не подходящие для Тихого Торга; бордели, бары, клубы с пунцем — трэш-музыкой нижних ульев и мутантов.
  • ⭐ Главарь местной банды «Талер», по совместительству управляющий гостиницей, — Оттон: арбитр под прикрытием, работающий на Халикарне. С виду бандит; выправку бывшего кавалериста в нём видит только тот, кто сам с феодального мира. Офицерский состав банды — арбитры из «крысиной службы» Арбитратума (сбор информации, кураторство информаторов).
  • Служба безопасности хорошо экипирована: аналог имперской кирасы, автоганы и лазганы из армейских партий, а не самоделки.
  • Жильё отряда: типовой контейнер. Сундуки вдоль стен, застеленные бельём вместо кроватей; самодельный алтарь Императора наполовину из свечного воска — стекающий воск скрывает, из чего пришлось возводить святилище. На время кислотных промывок контейнер герметизируется. Семь человек на контейнер. Снаружи выглядит нищим даже по меркам улья.
